# 📊 Power BI Sales Analytics Dashboard

An interactive **Sales Analytics Dashboard** built using **Microsoft Power BI and DAX** to analyze sales performance, profitability, customers, products, regions, payment modes, and salesperson performance.

The project focuses on transforming raw sales data into actionable business insights through **DAX measures, calculated columns, interactive visualizations, KPIs, and slicers**.

---

## 🚀 Project Overview

This project analyzes a sales dataset containing **1,000 orders** across multiple Indian cities, regions, products, categories, customers, and salespersons.

The dashboard provides a high-level view of business performance while allowing users to drill into sales and profitability using interactive filters.

### Key Business Questions

* What are the total sales and total profit?
* Which cities generate the highest sales?
* Which regions generate the highest profit?
* Which products contribute the most to sales?
* Which salespersons perform best?
* What is the average order value?
* What is the company's profit margin?
* Which payment modes generate the most sales?
* How do sales change over time?
* Which products have the highest contribution to total sales?

## 📁 Dataset

The dataset contains the following fields:

| Column       | Description                           |
| ------------ | ------------------------------------- |
| Order_ID     | Unique order identifier               |
| Order_Date   | Date of the order                     |
| Customer     | Customer name                         |
| Product      | Product purchased                     |
| Category     | Product category                      |
| City         | Customer/order city                   |
| Region       | Geographic region                     |
| Salesperson  | Salesperson responsible for the order |
| Quantity     | Quantity purchased                    |
| Unit_Price   | Selling price per unit                |
| Discount     | Discount applied                      |
| Cost         | Cost associated with the order        |
| Payment_Mode | Payment method used                   |
| Rating       | Customer rating                       |

The dataset contains **1,000 sales transactions**.
